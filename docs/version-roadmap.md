## v1.0 — MVP ✅ 已完成（2026-07-21）

**目标：** 验证核心同步功能可用

| 功能 | 状态 |
|-----|------|
| 文本剪切板自动同步（500ms 轮询） | ✅ |
| 端到端 AES-256-GCM 加密 | ✅ |
| 密码即账户（SHA256 派生 userId） | ✅ |
| 剪切板历史记录（100条） | ✅ |
| 多选拼接复制 | ✅ |
| 桌面轮询监听（macOS/Windows 500ms） | ✅ |
| Android 原生剪切板监听 | ✅ |
| 混合同步架构（全量 + 增量轮询） | ✅ |
| 垃圾箱系统（软删除 + 恢复 + 24h 自动清理） | ✅ |
| 同步健壮性（指数退避 + 删除防护 + 去重） | ✅ |
| 主密码解锁 + 同步状态指示器 | ✅ |
| 主题切换（浅色/深色/跟随系统） | ✅ |
| 阿里云自建服务器（Node.js + SQLite） | ✅ |
| Token 持久化 + 401 自动重新登录 | ✅ |
| 三平台构建产物（macOS DMG / Android APK / Windows EXE） | ✅ |
| 49 个单元/集成测试 | ✅ |
