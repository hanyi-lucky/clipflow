| Windows 代码 | ✅ | windows/runner 图片通道已实现（WIC），已真机构建验证 |

### v1.3 修复（2026-08-05）

- macOS 图片通道运行时注册修复（`super.applicationDidFinishLaunching` 之后的代码不执行，注册移到其前并直接绑定 engine messenger）
- 占位文本/二进制垃圾防护（"[文件]"等不再被当文本上传；NUL/乱码跳过）
- 历史列表接口瘦身（文本行 content 截断 10000，响应由 2.98MB → 123KB；`/history/:id/content` 完整返回）
- 长文本解密失败自动 `/content` 回补（历史 + 垃圾箱）
- 删除条目持久化（removeEntry 写回本地 + deletedEntryIds 防重启复活）
- 超限上传返回显式 413

| 垃圾箱预览 | ✅ | 文本/文件名/缩略图预览 |
| 兼容性说明 | ✅ | 设置页展示图片与文件格式兼容性 |
| Windows 文件通道 | ✅ | 标准 DROPFILES 双 NUL 终止，已真机验证 |

### v1.4 复测修复（2026-08-05）

- macOS 文件识别：普通文件（PDF/DOCX）不再被文件图标缩略图误判为图片，优先文件分支。
- Android：文件导入 MethodChannel 回调改主线程，修复滚动历史列表闪退。
- 历史/垃圾箱性能：超长文本 isolate 解密 + 50000 截断 + 列表 500 字符预览。
- 新增“倾倒垃圾桶”：一键从本地、服务器、磁盘彻底删除垃圾箱条目。
- 垃圾箱条目显示文本/文件名/缩略图预览。
- 文件签名只在上传成功后记录，失败后同文件可重试。
- 设置页新增“图片与文件格式兼容性”说明。
- Windows CF_HDROP 写入改为标准 DROPFILES 双 NUL 终止（已真机验证）。
- 当前测试：`flutter test` 215/215；`server/smoke-test.sh` 全绿（含倾倒垃圾桶步骤）。

### v1.4.1 Windows 图片文件识别修复（2026-08-06）

- Windows CF_HDROP 全部为图片文件时按图片识别，直接读取原文件归一为 PNG 上传，PNG 复制生成带缩略图的「图片」条目。
- 文件写回剪贴板后补充图片回声抑制，消除「Mac 来源重复图片」。
- 图片读取失败时回退文件分支兜底，不误传占位文本。
- 新增 3 个回归用例；`flutter test` 215/215；Windows release 构建通过。
