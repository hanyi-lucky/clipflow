# ClipFlow — 版本迭代计划

> 最后更新：2026-07-05
> 当前阶段：MVP 完善期

---

## v1.0 — MVP ✅ 已完成

**目标：** 验证核心同步功能可用

| 功能 | 状态 |
|-----|------|
| 文本剪切板自动同步（500ms 轮询） | ✅ |
| 端到端 AES-256-GCM 加密 | ✅ |
| 密码即账户（SHA256 派生 userId） | ✅ |
| 剪切板历史记录（100条） | ✅ |
| 多选拼接复制 | ✅ |
| 桌面轮询监听（500ms） | ✅ |
| Android 原生剪切板监听 | ✅ |
| macOS 系统托盘 | ✅ |
| 主密码解锁 | ✅ |
| 同步状态指示器 | ✅ |
| 主题切换（浅色/深色/跟随系统） | ✅ |
| 阿里云自建服务器（Node.js + SQLite） | ✅ |
| Token 持久化（服务器重启不丢失） | ✅ |
| 401 自动重新登录 | ✅ |

## v1.1 — MVP 稳定性（当前版本，进行中）

**目标：** 修复已知问题，确保双向同步可靠

| 功能 | 状态 | 说明 |
|-----|------|------|
| Mac → Android 同步 | ✅ | 已验证正常 |
| Android → Mac 同步 | ❌ | 上传端有问题，待排查 |
| 服务器重启后客户端恢复 | ✅ | token 持久化 + 401 自动重登录 |
| 不同密码数据隔离 | ✅ | userId 从密码派生 |
| 同步内容来源显示为 unknown | ❌ | 其他设备收到同步内容时，来源设备名显示为 "unknown" 而非实际设备名，待排查 |

## v1.2 — 体验优化

**目标：** 提升日常使用体验

| 功能 | 说明 |
|-----|------|
| 剪切板权限引导 | macOS/Android 首次使用时引导用户授权 |
| 网络状态检测 | 断网时显示离线状态，恢复后自动重连 |
| 同步失败重试 | 自动重试 3 次，失败后显示错误提示 |
| 历史记录搜索 | 按关键词搜索剪切板历史 |
| 条目内容预览优化 | 长文本显示更多行数，点击展开 |
| 启动速度优化 | 减少初始化等待时间 |

## v1.3 — 图片同步

**目标：** 支持复制图片跨设备同步

| 功能 | 说明 |
|-----|------|

## 技术债务

| 项目 | 说明 | 优先级 |
|-----|------|--------|
| 同步来源显示 unknown | 其他设备收到同步内容时来源设备名显示为 "unknown"，需排查 sourceDeviceName 传递链路 | 高 |
| 错误日志收集 | 添加 crashlytics 收集崩溃信息 | 高 |
| 单元测试覆盖 | 补充 Provider 和 Service 的测试 | 中 |
| 代码分割 | 大文件拆分（如 ClipboardProvider） | 低 |
| 国际化 | 使用 intl 包支持多语言切换 | 低 |
