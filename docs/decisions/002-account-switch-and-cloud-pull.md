# 002 · 切换账号优雅化 + 从云端拉取数据迁移

- 日期：2026-08-07
- 档位/组合：A 标准（coder→tester）；B 完整（explorer→architect→coder→tester→reviewer + 1 整改轮）

## 背景
- 用户反馈：切换账号必须杀进程重启（解锁页才有入口），体验差；希望有「从云端拉取旧账户数据」选项（已知密码 + 有网时比读备份文件更快）。

## 决策
1. 设置页「账户与数据」新增「切换账号」：警告对话框（请确认已导出备份…可用旧密码从云端拉取恢复）→ 确认后 `clearAccountIdentity()` + 导航回 `/unlock`（不杀进程）。
2. 「从云端拉取」：第二 `CloudBaseService` 实例读旧账户 → `buildCloudManifest`（强制 /content 全量密文）→ 复用 `importBackup` 管线（旧密钥解密 → 新密钥重加密 → 新 token 写新），服务端零改动。
3. `deriveUserId` 抽取为 `lib/core/user_id.dart` 单一实现（算法逐字节不变），消除双实现漂移。
4. 前置校验：同账户零网络拒绝；空账户/错误密码前置终止；目标非空且合并超 100 条时弹确认（服务端保留最近 100 条）。

## 后果
- 服务端零改动；迁移必须在客户端完成（新旧密钥不同，服务端只有密文）。
- 切换账号/云端拉取不删除云端旧数据（旧密码仍可恢复）。
- 红线（userId 派生、EncryptedData、PBKDF2、token 持久化、数据库结构）零触碰；真机冒烟由用户验收通过。
